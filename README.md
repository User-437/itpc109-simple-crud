
# ITPC109 - Simple CRUD Application

## Project Description
A Student Records Management System built using
PHP, MySQL, Docker, and phpMyAdmin.

## Features
- Create student records
- View student records
- Update student information
- Delete student records
- Manage data using MySQL

## Technologies Used
- PHP 8.2
- MySQL 8.0
- Apache
- Docker and Docker Compose
- phpMyAdmin
- Git and GitHub

## How to Run

1. Install Docker Desktop.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

   docker compose up -d --build

5. Open the application:

   http://localhost:8080

6. Open phpMyAdmin:

   http://localhost:8081

## Database
Database name: student_db

Table name: students
